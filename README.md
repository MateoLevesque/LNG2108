## À propos

Concepts-clés utilisés en linguistique de corpus comme la représentativité, le calibrage, l'échantillonnage, ainsi que plusieurs types de corpus linguistiques et les principaux enjeux liés à l'exploitation de ce genre de corpus comme l'annotation, les calculs, la visualisation). Introduction au langage R pour l'extraction et l'analyse des données textuelles à partir d'outils tels que les expressions régulières et les extensions pour R.

## Ce dépôt Git

Dans ce dépôt, vous trouverez les dossiers suivants pendant le cours :

- `donnees` : les données utilisées dans nos analyses de corpus
- `exercices` : les exercices de révision
- `extras` : des fichiers utiles
- `scripts` : les scripts `.R` du cours

## GitHub...?

Si vous n'avez jamais utilisé GitHub, consultez le document `intro_github.md` dans le dossier `extras`.

## Comment mettre à jour ce dépôt

Exécutez dans votre terminal (onglet « Terminal » sur Posit.cloud) la commande suivante :

```bash
git fetch origin && git reset --hard origin/main
```

Cela réinitialisera votre dépôt et toutes les mises à jour seront synchronisées dans votre projet.

## 🔥 Attention

- Si vous avez modifié le contenu des fichiers du dépôt, **ces modifications seront complètement perdues**. Toutefois, si vous avez créé des nouveaux fichiers pour vos notes, ils resteront dans votre projet. Les fichiers affectés par les commandes ci-dessus sont donc seulement ceux du cours. On vous recommande de créer vos propres dossiers et scripts pour vos notes, codes, etc.
